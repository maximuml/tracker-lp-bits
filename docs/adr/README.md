# Architecture Decision Records

This directory contains ADRs for the tracker-lp-bits project.

## Format

Each ADR follows the [Michael Nygard template](https://github.com/joelparkerhenderson/architecture-decision-record-template):

- **Title:** `NNNN-short-name.md` (e.g. `0001-nexus-web-guard.md`)
- **Sections:** Status, Context, Decision, Consequences
